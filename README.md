# GAS業務自動化スクリプト集

Google Apps Script (GAS) を使った業務自動化スクリプト集です。Claude API・Slackと連携したメール分類と、売上データの月次ダッシュボードを実装しています。

## スクリプト一覧

| ファイル | 概要 |
|----------|------|
| [email_classifier.gs](email_classifier.gs) | Gmailメールを自動分類してSlack通知 |
| [summary_dashboard.gs](summary_dashboard.gs) | 売上データを月次集計してグラフ生成 |

---

## email_classifier.gs

### 機能

- 「要処理」ラベルの未読メールを5分おきに自動処理
- **Claude API**（`claude-haiku-4-5`）でカテゴリ分類（クレーム／質問／注文／その他）と要約を生成
- スプレッドシートの「メールログ」シートに記録
- **Slack**で担当者に通知
- ラベルを「要処理」→「処理済み」に変更し既読化
- エラーは「エラーログ」シートに自動記録

### セットアップ

1. Googleスプレッドシートを開き、スクリプトエディタ（拡張機能 → Apps Script）でコードを貼り付ける
2. Gmail上に「要処理」ラベルを作成する
3. スクリプトプロパティを設定する（「プロジェクトの設定」→「スクリプトプロパティ」）

   | キー | 値 |
   |------|----|
   | `CLAUDE_API_KEY` | [Anthropic Console](https://console.anthropic.com/) で発行したAPIキー |
   | `SLACK_WEBHOOK_URL` | Slack App の Incoming Webhook URL |

4. `setIntervalTrigger()` を手動で一度実行してトリガーを登録する

### スプレッドシート構成

| シート名 | 内容 |
|----------|------|
| メールログ | 受信日時・送信者・件名・分類・要約 |
| エラーログ | 発生日時・件名・送信者・エラー内容 |

## summary_dashboard.gs

### 機能

- 「売上データ」シートから月別の合計売上・件数を集計
- 「月次サマリー」シートにデータを書き込む
- 月次売上推移の棒グラフを自動更新
- 毎朝9時の自動実行トリガーを設定可能

### セットアップ

1. スクリプトエディタでコードを貼り付ける
2. 「売上データ」シートを用意する（A列: 日付、D列: 金額）
3. 「月次サマリー」シートを作成する
4. `setDailyTrigger()` を手動で一度実行してトリガーを登録する

---

## 注意事項

- APIキーはスクリプトプロパティで管理し、コードに直接記述しないでください
- GASはブラウザ環境のため、Anthropic公式SDKは使用できません（`UrlFetchApp`で直接HTTP呼び出しを実装）
- 初回実行時にGmail・外部URLへのアクセス許可が求められます
